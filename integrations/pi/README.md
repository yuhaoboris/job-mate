# Pi 原生 UI 接入参考

**仅参考，不随核心分发，不是必须使用的方案。** Pi 是 runtime 的可选实现；本表描述 UI 能力映射，不提供执行器，也不宣称当前 Pi / 扩展版本均提供这些工具或已通过真实验收。接入时核对实际可用工具与返回格式，能力不足就按 [通用执行契约](../../shared/execution.md) 停止并报告，不放宽 [安全边界](../../shared/safety.md)、[台账](../../shared/ledger.md) 或 [通知](../../shared/notify.md)。

## UI 能力映射

| 核心所需能力 | 示例工具名（取决于所装扩展） | 接入时核对 |
|---|---|---|
| 找到已登录的可见浏览器窗口 | `find_roots` | 选择原生 window 根，不选需要 CDP 的 browser_page 根；核对网站、账号和窗口身份 |
| 读取所需页面区域 | `observe_ui`、`read_text` | semantic 结构不完整时，在工具策略允许范围内用 fused / visual 补充；必须确认目标区域完整才下否定结论 |
| 精确定位控件 | `search_ui`、`expand_ui` | 限定已核对会话 / 卡片；零匹配不能证明为空，导航或状态变化后重新观察 |
| 点击和输入 | `act_ui` | 使用当前观察返回的元素引用与 stateId；核对会话后才读写输入框，写后读回一致，再 guard、发送 |
| 等待可见状态变化 | `wait_for` 或动作 expect | 等待后先重读页面、重新 guard，不能沿用旧放行 |

表中名称仅帮助辨识扩展能力，不是 Pi 内置 API 或版本兼容承诺。任何通过 CDP 的浏览器工具都不能用于 BOSS；原生窗口导航通过地址栏和界面完成。有头模式不等于原生 UI。

## 接入边界

- runtime 加锁前验证所选工作区偏好；已选偏好无法满足时不操作平台、不回退。缺少外发结果证据时用禁发锁。
- 工具返回成功不等于业务发送成功。接入时验证请求 / 响应绑定、观察完整性、动作投递及进程收尾证据；未知格式或超时按 unknown，不把空页面或没有消息当作未执行证据。
- 未知草稿不清，no-send / L1 不碰外发输入框；不把输入和发送合并成一个动作。每个可能外发动作分别 guard。结果不明不换工具重发。
- Pi 宿主 / 扩展可能留存工具输出；仅取所需区域，不主动导出整页快照或个人数据。调度、单实例、超时、后代清理与防睡眠由选用的 runtime 自行保证，不由核心运行锁保证。
- 接入验证先用临时合成工作区 / 假 UI，不操作真实平台或 IM。工具名对照和静态规则通过不能替代真实 Agent 行为或本人发起的正式验收。
