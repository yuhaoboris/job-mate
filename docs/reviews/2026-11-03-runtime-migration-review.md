# Runtime 解耦：预发布审查与合成行为验证

## 范围与结论边界

- 核心保留 `ledger`、`workspace`、`notify` 的确定性业务状态；工具收发、浏览器操作、等待与进程管理由 runtime 提供。
- 自带桌面包装、IM 适配器、启动器、监听器与防睡眠实现已移除；具体接入参考在 `integrations/`，不随独立技能构建分发。
- 各阶段审查记录见项目状态：W/N/X/C 等阶段由 OpenAI 家族 Agent 实施、Claude 复审，并经父会话复核；最后的本地路由恢复文字按审查意见修正，由父会话核对。冻结行为版本：`f7a5cc00c763a053026c4d885cd1c4b2629c9d72`。
- 本报告不表示真实招聘平台、真实 IM、生产调度或所有 runtime 正式验收通过。CI、发布自动化、许可证由本人最后处理；没有远程创建、推送或发布。

## 实现与复审

| 阶段 | 已完成内容 |
|---|---|
| W | 工作区校验脱离执行工具；runtime / legacy 配置严格校验；旧草稿及步骤 ID 保留，旧 listener 答案标为未应用 |
| N | 本地排队、单次认领、令牌回执、入站、唤起状态；不执行工具或网络操作 |
| X/C | 删除旧执行器；完整读取、草稿保护、逐动作 guard、全部 attempt 收尾及进程责任提升为通用契约 |
| S/D | 三技能与两份平台事实同步；迁移说明、设计、安全和贡献文档同步 |

N 经多轮独立探针返工，最终复审无阻断。覆盖的重要修正包括：

- 幂等键首次交付后持久化，搬迁工作区不换键；不明投递重试保留原保证及不可延长的截止时间。
- 排队与认领双重验证回复目标，不能通过旧消息 ID 绕过收件人和私聊隔离。
- 编辑过的边界消息不再永久阻断整批入站及新的暂停指令；冲突内容不作为授权。
- 无身份旧记录须显式核对绑定；旧 ready 另须业务对账，旧指令不补执行或刷历史通知。
- 其他路由待办只报计数，不隐藏也不自动接管；新协议的增量记录不误报为旧历史。
- 追问确认 sent 后才允许 clarifying；缺引用元数据时要求新回复或本人明确处理。
- 临时恢复旧路由只能经 setup 的受控本地流程，预先停用 runtime 收发与调度，禁止认领旧队列，结束或中断后优先恢复新配置。

## 迁移后真实 Agent 合成抽查

运行环境：Pi 1.5.0，`openai-codex/gpt-6.1-sol`，high；最多两个受限 subject 并行。所有账号、消息、页面条件和工作区均为合成。

仅开放 `read / write / edit / ledger / workspace / notify` 六工具；没有 shell、UI、真实 IM、平台或 MCP 工具。合成 transport 不代 Agent 调用 incoming / receipt、不自动重试，也不隐藏重复投递。

最终隔离门禁实际执行 2 个允许调用、10 个负向调用；越界路径、控制目录、符号链接、参数覆盖、未知模式及伪造 claim 被拒绝；工具子进程实际 connect / bind / fork 被 OS 拒绝，未带凭据。首轮门禁因夹具隔离导入错误未通过，业务未启动；修正夹具路径后完整重验，没有放宽隔离。

**首批 23 次业务运行：22 通过、0 失败、0 不可达、1 未覆盖。** 没有业务补跑或模型故障。

|---|---|

父会话核对了 **917 个证据文件摘要**、23 例台账前缀及工具范围；逐条确认 29 个新增 sent 回执对应实际合成 transport 的 key / token / messageId / chatId / createTime。30 次合成投递产生 29 个 sent 与 1 个 unknown，无同 key/token 重复投递。F1/F2 的通知与事件增量已独立复核；仅证明无需动作或已完成事项的本地收尾，不外推无 UI 时能执行尚未完成的平台动作。

22 例运行锁已释放。N12d 因故意损坏 ledger，release 被拒；Agent 明确报告未完全收尾并保留合成锁，没有删锁掩盖错误，subject 进程已退出。此例不能算清洁释放。

**S02 单次补测通过**：从 S01 实际结束状态克隆，在合成用户明确确认后触发 `progress finish`，返回 finished=true；原答案保留至完成、草稿清除、listener 明确未应用，profile 和业务台账原字节不变，运行锁合法释放。新根重新通过完整隔离门禁；一次只读 changed 调用被原白名单拒绝，没有放宽权限。父会话复核新增 118 文件摘要、实际 finish 响应及前后文件差异。

累计 24 次业务运行：23 pass、1 uncovered（原 S01 判档保留），无业务重跑。S01→S02 只补齐该旧 partial 草稿的两阶段路径，不代表 setup 全面验收。证据根与原始工具轨迹私下保留，不把本机定位、凭据或完整会话日志纳入公开仓库。
