# job-mate · 职伴

给 AI Agent 使用的求职助手技能，目标是帮你争取更多面试机会。首批支持 BOSS 直聘：你提供真实经历与求职条件，Agent 做重复工作，关键决定由你拍板。

| 技能 | 能做什么 |
|---|---|
| `job-mate-setup` | 建立工作区，确认偏好、个人事实、简历、沟通风格和权限 |
| `job-mate-apply` | 搜索、读详情、筛选去重；授权后发起首次沟通，也能只筛选 |
| `job-mate-followup` | 检查HR消息、有依据代答、应请求发简历、按配额主动跟进；需决定时通知你 |

## 关键原则

- 只在你授权范围内外发。本轮“只看看”、目标与数量限制优先于长期权限；不编造经历、数字或资格。
- 代答与主动跟进独立：默认L2有依据代答、主动跟进开启；你可以分别关闭。承诺类事项仍交你决定。
- Agent 不自行答应、也不提出任何面试时间。你批准的文字原样发送，不擅自改写。
- 遇验证码、访问限制或风控立即停止，不模拟人工、不规避检测；发送结果不明不重发。
- 首次沟通不是简历投递；Agent不会为了凑数量降低筛选条件。

## 风险与隐私

自动操作招聘平台可能违反其用户协议，账号可能被限制或封禁；请先确认平台规则，理解并自行承担使用后果。脚本与规则不保证平台兼容、消息必达、不会重复判断，也不保证获得面试。

偏好、沟通记录、个人事实和简历只放在你的求职工作区，不进入代码仓库。**聊天与简历可能经过你所用Agent的模型服务，并留在其本地日志中**；这不等于数据从未离开设备。请核对Agent与模型服务的隐私政策，不提供不必要的证件、银行卡或凭据。登录、扫码、验证和解锁由你本人完成。

## 运行要求

- Python **3.9+**，支持 macOS、Linux 与原生Windows；脚本只用标准库。
- 能读写工作区、运行命令、完整读取并操作本机可见浏览器的Agent。能力不足会停止，不把“可自动化”当作已执行。
- macOS条件满足时优先选agent-desktop；其他情况需Agent提供非CDP的原生桌面/辅助功能操作。具体能力、版本与限制以[浏览器入口](shared/browser/README.md)为准，不代表所有环境已经实测。
- 飞书通知需lark-cli和你自己的机器人应用，按setup核对身份并单独同意测试。不需要通知可选none，仍保留本地inbox。

BOSS仅通过你日常已登录的可见浏览器操作，不使用CDP/Playwright、无头访问或内部接口。使用时保留前台环境；输入、逐字读回、发送与业务结果核对分开执行。

## 必须整套安装

三个技能共享版本与协议，不支持单独安装一个。在代码目录运行：

```sh
python3 scripts/build.py --install <你的Agent技能目录>
```

原生Windows：

```powershell
py -3 scripts/build.py --install <你的Agent技能目录>
```

技能目录按你的Agent文档选择，这里不预填未经核实的产品路径。命令会同时构建并安装三个自包含目录；每份都有所需规则、脚本和平台描述。重新运行可整套更新，误删其中一个后也可恢复整套。只构建、不安装时用 `--out <临时产物目录>`。

安装/更新前暂停使用整套技能。安装器只替换未修改的受管目录，不覆盖手工修改、额外文件或其他技能；遇拒绝先按提示将旧包整体迁出技能扫描目录，不只删清单。可回滚批次失败，但不保证运行中的Agent看不到中间版本，也不提供断电自动恢复；有错误或warnings请保留现场与备份。

## 开始使用

1. 让Agent运行 **job-mate-setup**，选独立工作区，确认真实材料、筛选条件与权限。求职工作区不需要Git。
2. 先让 **job-mate-apply**“只筛选不发送”，核对结果后再明确授权目标与数量。
3. 让 **job-mate-followup**处理消息。面试、薪资承诺、联系方式等由你决定；在飞书或终端确认草稿后才执行。
4. 需要定时巡检时，由你的Agent或系统调度followup，并确保实例互斥。职伴不自建常驻后台；失锁、环境受阻或结果不明时先按提示处理，不自动重放发送。

以后改变长期条件或默认授权，请通过setup同步。首次使用、小批量使用并保留人工观察，确认Agent实际遵守规则后再扩大范围。
