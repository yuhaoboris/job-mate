# job-mate · 职伴

让 AI Agent 帮你找工作，争取更多面试机会。首批支持 BOSS 直聘：你提供简历和想找的工作，Agent 帮你筛选、打招呼、处理 HR 消息；关键决定由你拍板。

## 先装好

把这句话发给你的 Agent：

> 请按 https://github.com/yuhaoboris/job-mate 的 INSTALL.md 安装 job-mate。

Agent 会确认装在哪里，整套安装三个技能，并自动补齐必要的软件依赖、检查运行环境，不逐项询问安装同意。你不用自己下载、复制文件或挑选技能；系统授权、登录、扫码仍需你完成。需要能运行本机命令的 Agent；脚本支持 macOS、Linux、原生 Windows，桌面能力另行检查，远程或无桌面环境不能保证操作本机浏览器。

[给 Agent 的安装指引](INSTALL.md) · [手动安装与维护](docs/installation.md)

## 然后开始

对 Agent 说：

> 开始求职设置。

准备好你的简历。Agent 会先读，再带你确认想找的职位、城市、薪资、不考虑的公司和沟通权限，共 8 屏，大约十分钟。这次设置不会在招聘平台发消息；飞书提醒可以以后再配。求职资料放在你确认的独立目录，不需要懂 Git。

接下来可以这样说：

- **先看看**：「帮我在 BOSS 上找合适的岗位，只筛选，不发送。」
- **试着沟通**：核对筛选结果后，明确允许联系哪些岗位、最多几个。
- **处理消息**：「看看 HR 的回复，帮我处理有把握的问题，需要我决定的告诉我。」
- **以后调整**：「修改求职条件」或「部分重新设置」。没做完可以说「继续 setup」。

| 技能 | 负责什么 |
|---|---|
| job-mate-setup | 整理简历、求职条件与权限 |
| job-mate-apply | 找岗位、筛选；授权后发起首次沟通 |
| job-mate-followup | 处理回复、应请求发简历、按节奏跟进 |

## 你始终掌握决定权

- 主动打招呼默认关闭；有依据的问题直接回答、对方不回时按节奏跟进默认开启。这三项分别确认，也可以分别关闭。
- 面试时间、薪资等承诺由你决定。Agent 不答应、也不提出任何面试时间；你批准的文字原样发送，不改写。
- 「只看看」优先于长期授权。不编造经历、数字或资格，不为凑数量降低条件。
- 验证码、访问限制或风控出现就停，不模拟人工、不规避检测；发送结果不明不会重发。

## 使用环境

BOSS 只通过你日常已登录的可见浏览器操作，不使用 CDP/Playwright、无头访问或内部接口。Agent 必须能读写工作区、运行脚本，并通过本机桌面或辅助功能读取和操作浏览器；不是所有 Agent 或云端环境都具备这些能力，能力不足会停止。操作键盘鼠标需要你单独允许，使用时保留前台环境。

macOS 优先使用 agent-desktop：Agent 会补齐工具、加载同版操作 skill，并引导你完成权限设置；其他环境需已有原生桌面/辅助功能能力，详见 [浏览器入口](shared/browser/README.md)。选择飞书提醒后，Agent 再安装对应依赖并引导机器人配置；应用授权、本人身份和测试内容由你确认。暂不配置也能在本地查看待决定事项。

如需定时检查消息，可让 Agent 或系统调度 followup；职伴不自建常驻后台。先小批量使用并保留人工观察，再考虑扩大范围。

## 风险与隐私

自动操作招聘平台可能违反其用户协议，账号可能被限制或封禁；请先确认平台规则，理解并自行承担使用后果。脚本与规则不保证平台兼容、消息必达，也不保证获得面试。

偏好、个人事实、沟通记录和简历只放在你的求职工作区，不进入代码仓库。**聊天与简历可能经过所用 Agent 的模型服务，并留在其本地日志中**，不等于数据从未离开设备。请核对隐私政策，不提供不必要的证件、银行卡或凭据。登录、扫码、验证和解锁由你本人完成。
