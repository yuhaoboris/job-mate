# 浏览器操作与页面核验

## 浏览器选择

开始浏览器操作前，检测本地命令：macOS/Linux 用 `command -v`，Windows PowerShell 用 `Get-Command`。

1. 优先使用 `ego-browser`（ego browser）。
2. 仅当本地找不到 `ego-browser` 时，回退到 `agent-browser`。
3. 两者都未安装时，告知缺失工具，等待本人安装；不自动安装。

先读取所选工具的 `--help`，按其支持的方式连接本人已登录的可见浏览器。已安装但连接失败、未登录或遇到平台限制时，报告具体阻塞，不以切换工具绕过。

## 外发核验

用页面账号、公司、职位和招聘者确认目标。登录、验证码和系统权限由本人处理；只操作可见页面，不用隐藏接口或绕过平台限制。

页面发送与本地写入不是原子操作：先按[数据命令](protocol.md) prepare，每次可能外发前 guard，事后以页面证据 finish。结果不明时不重发。

## 首次沟通入口后的分支

「立即沟通」可能自动发出招呼。点击后查看会话、消息时间和状态，页面跳转不代表送达。

| 页面结果 | 处理 |
|---|---|
| 本次招呼已发 | 登记实际原文，只计一条，即使与计划不同也不补发。 |
| 点击前已有沟通 | 不算新招呼；按最后一条消息决定回复或跟进。 |
| 历史已加载，确认未发 | 固定语或动态语发准备好的原文；平台预设用页面快捷语，不输入意图标记。预设不可用则跳过并说明。 |
| 已有草稿 | 保留草稿，跳过该会话。若入口可能已外发，仍核对结果。 |
| 加载中、超时或结果不清 | 只读核对；仍不明则登记不明、暂停外发。列表可读就继续检视到末尾。 |

手动发送前核对会话、输入框和原文，确认没有迟到的自动招呼。发送后据气泡和状态[登记结果](protocol.md)。
