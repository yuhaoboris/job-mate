# 浏览器操作入口

准备浏览器、输入、可能外发或停止时，先读 [通用执行契约](../execution.md)；它适用于所有 runtime，而非某个工具的附加规则。授权与风险见 [安全边界](../safety.md)，配置结构见 [工作区](../workspace.md)。

1. **加锁前**由 runtime 自检读取、定位、点击、输入、截图核对及结果证据能力。工作区选定偏好不能满足时不操作平台、不回退；缺外发证据用禁发锁。
2. BOSS 只操作本人日常已登录的可见浏览器，通过辅助功能树或桌面 UI；不使用 CDP / Playwright、无头浏览器或内部接口，不模拟人工、不规避检测。
3. 核对网站、账号、窗口和会话后再操作；页面变化后重新观察和定位。完整读取才下否定结论，未知草稿保留，输入和发送分开核对。
4. 可能外发前逐动作 guard；等待后重读再 guard。工具超时不是未执行，可能已执行或未知不重发。
5. 页面空白、异常跳转或工具受阻时停止导航、点击和刷新，保留可见地址、页面状态和最后动作的最小证据；按 [尝试阶段与停止前收尾](../execution.md#6-尝试阶段与停止前收尾) 处理全部 attempt、释放与对账，再向本人说明原因、恢复办法和重新发起方式。安全信号优先，不换工具重试。

工具名和有头模式不能证明操作的是原生窗口。具体工具能力由 runtime 在接入时核对；本入口不提供执行器或工具调用步骤。
