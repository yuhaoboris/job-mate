# 浏览器操作入口

准备、输入、外发或停止时读 [通用执行契约](../execution.md)；授权与风险见 [安全边界](../safety.md)，配置见 [工作区](../workspace.md)。

1. **加锁前**按[能力自检与唯一工具选择顺序](../execution.md#1-加锁前能力自检)判断，不在此另定义工具优先级。选用 agent-desktop 即读其[随包规则](agent-desktop.md)，核对实际版本、格式与能力。
2. 工作区不记录工具名；既定偏好不满足时不操作平台、不回退。缺外发证据用禁发锁。选择顺序不授权运行中换工具或换输入方式重发；锁屏先请本人解锁，不换通道绕过。
3. BOSS 只操作本人日常已登录的可见浏览器，经辅助功能树或桌面 UI；不使用 CDP / Playwright、无头浏览器或内部接口，不模拟人工、不规避检测。
4. 核对网站、账号、窗口和会话后再操作，页面变化重新观察定位。完整读取才下否定结论，未知草稿保留，输入与发送分开，逐动作 guard；工具成功不等于业务送达。
5. 页面空白、异常跳转、工具受阻或结果未知时，停止导航、点击和刷新；按 [尝试阶段与停止前收尾](../execution.md#6-尝试阶段与停止前收尾) 处理全部 attempt、释放与对账，报告最小证据、原因、恢复办法及重新发起方式。安全信号优先，不换工具重试。

这里只是随包规则入口，不是执行器；具体命令和实际版本仍须核对。
