# 提问与对话

setup、apply、followup 对话共用；需本人选择、补充或确认时，按以下能力选界面。

## 对话规则

- 只说结果，不讲过程：读规则、自检、加锁、对账、备份都不播报。用本人的语言说话；操作失败也只给一句人话和一个照做就行的办法，不把技术方案摆给本人选。
- 先读本人本轮提供的材料再提问，问题从简历里来；材料已回答的不重复问，只确认推断或缺口。能默认的直接默认，一句话说明以后可改。
- 对本人说话时不出现字段名、步骤 id、L1/L2、锁、事务或备份名。技术标识只供 Agent 执行，不照搬成问题或汇报。
- 本人批准的外发文字原样发送，不因对话简化而改写。

## 能力选择

先检查本轮工具；按需加载时先查找一次提问工具再决定是否退回纯文本。只调用实际可用工具，不根据 Agent 名称编造调用。

| Agent | 提问工具 | 条件 |
|---|---|---|
| Claude Code | `AskUserQuestion` | 本轮可用时使用 |
| Cursor | `AskQuestion` | 本轮可用时使用 |
| Codex | `request_user_input` | 仅 Plan Mode 可用；其他模式退回编号纯文本 |
| DeepSeek Harness | `ask_user_question` | 不限于 Plan Mode；本轮工具列表里出现就能用，不在列表里才退回编号纯文本 |

DeepSeek Harness 的 `ask_user_question` 参数为 `questions[]`：每项必填 `id`、`question`，可选 `header`、`options[{label, description}]`、`multi_select`。带 `options` 时呈现选择卡片，多个问题可一次问完；可不选任何选项直接跳过。

## 卡片

- 一屏一次卡片调用，屏内多题放同一张卡里翻页；一次最多 4 题，每题 2–4 个选项。setup 的新建屏划分只取脚本 `currentScreen`，重新设置与部分重新设置仍按步骤。
- 推荐项放第一个并标「推荐」。选项用白话说明后果，不出现字段名或步骤 id。
- 不另加「其他」选项，使用卡片自带自由输入。姓名、薪资数字等手填内容，把从简历推得的建议值做成选项；没有依据就请本人自由填写，不捏造建议。
- 简历先在对话中请本人提供；长草稿（个人事实、招呼语）先展示，再用卡片问「可以 / 改几处 / 重写」。同屏选语气时，先展示各语气草稿，再同卡确认语气与正文。
- 卡片空选择 = 跳过本题，只是问题回答，不能当作对平台操作或 Agent 审批请求的批准。必答项被跳过时说明原因后重问。
- 新建第 7 屏跳过时按默认处理：主动打招呼关闭、有把握的问题直接回答（L2）开启、对方不回时跟进开启。跳过不能开启默认关闭的权限；首次沟通 apply.send 只能由本人明确同意开启。汇总单独列出三项及来源（本人选择 / 默认），以本人在汇总卡上「确认保存」为准。
- 回答仍逐项经 `workspace progress record` 落盘。卡片只是界面，不代替事实核对、独立授权或保存确认；返回复核或修改仍留在对应屏。

## 编号纯文本

无卡片时，每屏一条编号消息，内容不变。开始时只说一次「可以说『上一步』或『先到这』」，不在每一步重复。重新设置与部分重新设置每步一条，预填本工作区当前值。
